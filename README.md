# ExtraDim
an extra brightness lowering tool for Windows. 

Since the original executable folder is bigger than 25MB, i'm not able to upload it here. 

To run it, you'll have to open it in an IDE, and keep the IDE running as well.

For a standalone executable: 

1. Install PyInstaller
In the same terminal/environment where your script works: python -m pip install pyinstaller
Then run: python -m PyInstaller --onefile --windowed --name "Extra Dim" extra_dim.py

The shortcut key to terminate this program is: Ctrl+Shift+Alt+E
In case you set the screen colour to black, press Ctrl+Shift+Alt+E
